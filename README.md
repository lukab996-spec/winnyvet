# Winny Vet - sajt

Statička verzija sajta veterinarske ambulante Winny Vet (Niš), spremna za hostovanje.

## Postavljanje na GitHub Pages

1. Napravite novi repozitorijum na GitHub-u i otpremite sav sadržaj ovog foldera (fajl `index.html` mora biti u korenu repozitorijuma).
2. U repozitorijumu idite na **Settings → Pages**.
3. Pod **Build and deployment → Source** izaberite **Deploy from a branch**.
4. Za granu izaberite `main` i folder `/ (root)`, pa sačuvajte.
5. Nakon minut-dva sajt je dostupan na `https://<korisnicko-ime>.github.io/<ime-repo>/`.

## Napomene

- Fajl `.nojekyll` i folder `theme/` (umesto naziva sa donjom crtom) obezbeđuju da GitHub Pages učita stilove ispravno.
- Fontovi (Google Fonts), ikonice i Google mapa se učitavaju sa interneta, pa je potrebna internet konekcija pri otvaranju.
- Sve fotografije se nalaze u folderu `assets/`.
